# PROJECT: Retail Demand Forecasting Pipeline

Portfolio project for resume building.
## What it does:
Predicts store sales for next 30 days using Prophet ML
Shows forecasts on interactive Streamlit dashboard
Alerts when stores risk running out of stock
Automatically retrains models weekly via GitHub Actions
## Why it's built:
Demonstrates end-to-end ML pipeline: ETL → Training → Dashboard → Deployment
Solves real business problem: inventory management for retail chains
Shows practical skills: Python, SQL, ML, DevOps, web UI
## Dataset:
Rossmann supermarket sales (1115 stores, 2 years history)
## Stack:
Python → MySQL → Prophet → Streamlit → GitHub Actions → Cloud
## Portfolio value:
Technical depth: 1115+ ML models, 33K+ predictions, star schema DB
Full-stack: backend (ETL/ML) + frontend (dashboard) + DevOps (CI/CD)
Production-ready: automated retraining, error handling, cloud deployment
